# 🧠 Key Learnings

## Overview

This project provided practical exposure to the integration of **SIEM and SOAR technologies** within a SOC workflow.

---

## 🛡️ SIEM & Security Monitoring

Working with Wazuh helped reinforce the role of a SIEM in:

- Collecting security events
- Monitoring activity
- Detecting relevant security events
- Generating security alerts
- Supporting security investigations

---

## ⚙️ SOAR & Automation

Working with Shuffle SOAR provided exposure to how security automation can support SOC operations.

Key concepts included:

- Automated alert processing
- Workflow-based security operations
- Alert enrichment
- Response workflow automation
- Reducing repetitive investigation tasks

---

## 🔎 Alert Investigation

The project helped demonstrate the importance of having additional context when analysing security alerts.

Alert enrichment can provide analysts with information that helps them better understand the detected activity and determine the appropriate next steps.

---

## 🔗 SIEM-to-SOAR Integration

One of the main takeaways was understanding how SIEM and SOAR platforms can complement each other:

**SIEM → Detection**

**SOAR → Automation & Orchestration**

Together, they can support a more structured security alert lifecycle.

---

## 📊 Monitoring & Visualization

The project also provided exposure to security event visualization and dashboards.

This highlighted the importance of centralized visibility when monitoring security activity and analysing events.

---

## 🎯 Overall Takeaway

The project strengthened my understanding of how **detection, alert processing, enrichment, automation, investigation, and response** can be connected as part of a SOC workflow.

```text
Detection
    ↓
Alert Processing
    ↓
Enrichment
    ↓
Investigation
    ↓
Response
```

## 📌 Conclusion

This project provided practical exposure to building a security monitoring and automation workflow using Wazuh and Shuffle SOAR.

It helped demonstrate how SIEM-based detection can be combined with SOAR capabilities to support alert enrichment, investigation, and response within a SOC environment.
